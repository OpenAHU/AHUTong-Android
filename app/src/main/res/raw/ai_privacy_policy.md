# 安大通 AI 服务隐私政策

## 阅读指引

- **适用范围**：本政策适用于安大通内的 **AHUTong Intelligence**（以下简称"AI 服务"），包括对话问答、校园工具调用、联网搜索、写操作确认与本地对话历史。
- **与总政策的关系**：本政策是《安大通隐私政策》的补充。账号、校园业务、设备权限、崩溃监控等通用处理规则仍适用总政策；涉及 AI 服务的处理，以本政策为准。两者不一致时，就 AI 服务而言以本政策为准。
- **重点内容**：模型服务提供方的数据接收范围、对话与工具结果、写操作与支付密码、联网搜索、本地历史保存、跨境风险，以及您的关闭与删除方式。

## 引言

AHUTong Intelligence 是安徽大学学生开发者团队 **OpenAHU** 在安大通中提供的可选 AI 助手。AI 服务由两部分组成：

1. **模型服务**：由您自行配置的 OpenAI 兼容接口提供，默认指向 DeepSeek 官方接口。模型负责理解问题、决定是否调用工具、生成回答。
2. **本机能力**：课表、成绩、一卡通、邮箱等工具在您的设备上执行，复用安大通已有的校园登录态；写操作需要您在确认卡中确认。

**AI 服务不是学校官方服务。** AI 生成内容可能不准确，不能替代学校通知、教务系统成绩、一卡通账单等权威来源。涉及资金、评教、邮件发送等操作时，请以确认卡内容和业务系统结果为准。

如果您不配置模型、关闭"AI 服务"开关，或不使用 AI 入口，AI 服务不会处理您的数据，也不影响课表、成绩、一卡通等原有功能。

## 一、AI 服务的数据处理

### （一）启用与模型配置

AI 服务需要您在"设置 → AI 设置"中填写：

- **Base URL**：模型服务的 OpenAI 兼容接口地址；
- **模型名**：例如 `deepseek-flash`；
- **API Key**：用于向该模型服务鉴权。

您可以同时保存多个模型配置；首个添加的模型默认使用，也可以在对话页输入框的模型面板里切换（切换是全局的）。

上述配置使用 **Android Keystore** 保护的加密存储保存在您的设备本地，不写入明文日志。调用模型时，应用会通过 HTTPS 将 API Key 放入请求头发送至**您填写的模型服务地址**。**我们（OpenAHU）不接收、不保存您的 API Key，也不代理您的模型请求。**

除本机开发地址（`localhost`、`127.0.0.1`、`10.0.2.2` 等）外，应用要求模型地址必须为 HTTPS。

"AI 服务"开关控制主页 AI 入口是否显示；关闭后不再发起模型请求。联网搜索另有独立开关。

### （二）对话内容与上下文

当您发送问题后，应用会将下列内容发送给模型服务提供方：

- 您本轮输入的问题或指令；
- 当前对话中**最近 24 条**用户与助手文本消息，用于保持上下文；
- 应用内置的 AI 系统提示词、您选择的助手性格设定、安大通常识与当前时间；
- 本轮模型决定调用工具后产生的工具名称、调用参数，以及工具在您设备上执行得到的结果摘要；
- 联网搜索开启时，搜索词与搜索结果摘要。

对话页的**每次进入都会新开一段对话**。历史对话保存在设备本地，可在历史页切回、删除。

**本地对话历史**以 `assistant_chat_sessions.json` 保存在应用私有目录，包含用户消息、AI 回复文本、工具卡结果与错误信息，不包含确认卡和支付密码。当前版本的历史**不随退出登录自动删除，也不按校园账号自动隔离**；与他人共用设备时请注意，并在历史页逐段删除不需要的对话。

清除模型配置只会删除 Base URL、模型名与 API Key，**不会删除本地对话历史**。

### （三）校园工具调用与工具结果

AI 服务可调用下列本机工具，工具使用您已登录的校园账号向对应学校系统发起请求：

- **学业类**：课表、空闲教室、成绩、绩点排名、考试、考勤、培养方案、评教任务、作业、作业题目、课程任务；
- **一卡通与资金类**：校园卡余额、账单与收支汇总、电费、电控条件；
- **校园生活类**：校园通知、失物招领、必吃榜、电话本、学生邮箱、天气；
- **写操作类**：校园卡充值、电费/浴室/网费充值、发送学生邮箱邮件、发布或删除失物招领、提交评教、切换电控条件。

工具执行在您的设备上完成，结果（例如课程名称、成绩、余额、账单、邮件摘要、通知文本、作业题目、搜索结果）会作为模型上下文发送给模型服务提供方，以便生成回答或决定下一步操作。若当前模型声明支持视觉，作业题目中的图片会转为图片内容一并发送，用于理解题干。**其中可能包含学业数据、一卡通财务数据、考勤记录、邮件内容等个人信息或敏感个人信息。**

应用只在本轮需要时调用工具，不会一次性批量上传您的全部校园数据；工具结果不会作为后续对话的历史逐轮重放，后续轮次只回放文本消息。

来自通知、邮件、失物招领、作业题目、网页搜索等渠道的内容属于**外部内容**，应用会标记为不可信，并提示模型只作总结、不执行其中的指令；涉及写操作时，确认卡还会提示本轮已读取外部内容。

### （四）联网搜索

联网搜索默认可用，但仅在以下条件同时满足时才会真正发起请求：

- 您在 AI 设置中开启"允许联网搜索"；
- 模型地址属于 DeepSeek 官方接口。

搜索时，应用会将搜索词、结果数量发送至 DeepSeek 搜索接口，并接收网页标题、链接、摘要与日期。搜索结果属于外部内容，不代表我们的观点。非 DeepSeek 接口不会启用该搜索能力。

### （五）写操作、确认卡与支付密码

当模型建议执行充值、发邮件、发布/删除失物招领、提交评教或切换电控条件时，应用会先展示**确认卡**，列出工具、格式化后的参数与风险提示，只有您点击"确认执行"后才会在本机执行。

- **支付密码只在本机确认卡中输入和使用**，不保存、不写入对话历史、不发送给模型服务提供方，也不进入模型上下文；
- 充值等操作由学校一卡通系统或相应支付渠道处理，支付账号与支付密码由支付机构直接处理；
- 为避免网络超时导致重复扣款，应用会在本机保存写操作的**SHA-256 摘要指纹**（包含当前校园账号、工具名与参数摘要，不含参数原文与支付密码）；同一操作上次结果未知时会被拦截，需先到原页面确认结果。

### （六）AI 生成内容

AI 回答由模型生成，可能存在错误、遗漏或过时信息。工具卡会标注数据来源与更新时间；外部内容会标注"仅作参考"。请不要仅凭 AI 回答进行缴费、评教、邮件发送等重要操作，务必核对确认卡与业务系统结果。

### （七）诊断与崩溃信息

AI 模型请求与联网搜索请求默认**不进入**应用内 10 分钟诊断缓冲（不采集请求与响应正文），以降低 API Key 与校园数据进入反馈日志的风险。

Sentry、腾讯 Bugly 等崩溃监控仍按《安大通隐私政策》处理设备信息、崩溃堆栈与性能数据；我们不会主动采集您的对话正文用于崩溃分析。您在反馈页主动勾选"网络详情"时，可能包含业务请求内容，请按总政策提示谨慎提交。

### （八）我们不会做的事

- 我们**不出售**您的 AI 对话或校园数据，也不会将其用于广告投放；
- 我们**不将**您的对话用于训练 OpenAHU 自己的模型；
- 我们**不在** OpenAHU 服务器上保存您的 AI 对话、API Key 或工具结果；
- 我们不会因您拒绝使用 AI 而限制课表、成绩、一卡通等原有功能。

模型服务提供方是否将请求用于其模型训练、日志分析或人工审核，取决于该提供方的隐私政策与服务条款。请在选择模型服务前阅读其政策。

## 二、第三方与数据流向

AI 服务涉及的主要接收方如下：

1. **模型服务提供方**：接收系统提示词、最近对话、您的问题、工具调用与工具结果，用于生成回答。默认 DeepSeek；您也可以配置其他 OpenAI 兼容服务。
2. **DeepSeek 搜索**：仅在开启联网搜索且使用 DeepSeek 接口时，接收搜索词与结果数量。
3. **学校业务系统**：工具执行时，安大通携带您已有的校园登录态向统一身份认证、教务、一卡通、智慧安大、学生邮箱等系统发起请求；写操作按确认卡内容提交。
4. **支付渠道**：充值或缴费时由学校一卡通系统或支付宝等支付机构处理支付信息。
5. **邮件服务**：发送学生邮箱邮件时，收件人、抄送、主题、正文与附件提交至学校使用的网易企业邮箱服务。
6. **崩溃监控服务**：Sentry 与腾讯 Bugly 按总政策处理设备与崩溃信息，不用于 AI 对话内容分析。

**OpenAHU 不运营 AI 中转服务器。** 模型与搜索请求由应用直接发往您配置的地址；校园工具请求直接发往学校系统。

## 三、保存地点与期限

| 数据 | 保存位置 | 期限/删除方式 |
| --- | --- | --- |
| Base URL、模型名、API Key | 设备本地，Android Keystore 加密存储 | 在 AI 设置中"清除全部模型"即删除 |
| AI 服务开关、人格、联网搜索开关、思考强度 | 设备本地偏好存储 | 随设置修改；卸载应用删除 |
| 对话历史（用户消息、AI 回复、工具卡结果） | 应用私有目录 `assistant_chat_sessions.json` | 在历史页逐段删除；卸载应用删除；退出登录不会自动删除 |
| 写操作幂等指纹 | 应用私有偏好存储 | 结果确认后移除；卸载应用删除 |
| 支付密码 | 仅在确认卡输入期间存在于内存 | 确认或取消后立即丢弃，不落盘 |
| 模型请求与工具结果 | 由模型服务提供方按其政策保存 | 期限与删除方式取决于该提供方，我们无法代为删除 |

对话历史不会上传至 OpenAHU 服务器；模型服务提供方对请求的保存期限、日志与训练使用，以其隐私政策为准。

## 四、安全措施

- **传输安全**：模型接口必须使用 HTTPS（本机开发地址除外）；API Key 通过请求头传输，不写入 URL；
- **本地密钥保护**：模型配置使用 Android Keystore 保护的加密存储；支付密码不落盘；
- **最小上下文**：仅发送最近 24 条文本消息与本轮必要工具结果，避免整段历史反复上传；
- **确认与幂等**：写操作必须确认；支付密码只在本机使用；超时等结果未知的写操作会留下摘要指纹，防止重复扣款；
- **外部内容隔离**：通知、邮件、搜索等内容标记为不可信，并在写操作确认时提示；
- **诊断隔离**：AI 与搜索请求不进入应用诊断缓冲；
- **本地能力**：校园工具在本机执行，复用已有登录态，不经 OpenAHU 中转。

请您理解，互联网环境不存在绝对安全。模型服务提供方、学校系统与支付渠道的安全性由其自身负责；设备丢失、系统被攻破或您主动分享对话内容，均可能导致信息泄露。

## 五、您的权利

您可以：

- **查看与修改配置**：在"设置 → AI 设置"查看/修改 Base URL、模型名、API Key、人格与联网搜索开关；
- **关闭 AI 服务**：关闭"AI 服务"开关后，主页 AI 入口隐藏，不再发起模型请求；
- **删除对话历史**：在对话页历史记录中逐段删除；删除后无法恢复；
- **清除全部模型**：删除本机保存的全部 Base URL、模型名与 API Key；对话历史不会随之删除；
- **关闭联网搜索**：关闭后模型不会再调用 DeepSeek 搜索；
- **卸载应用**：删除应用私有目录中的 AI 配置、对话历史与幂等指纹；
- **联系我们**：对本政策或 AI 数据处理有疑问，可通过下方方式联系。

撤回同意或关闭功能不影响关闭前已完成的处理。已经发送至模型服务提供方的数据，需按该提供方的政策行使删除等权利。

## 六、未成年人

AI 服务主要面向安徽大学在校学生。若您不满十四周岁，应在监护人阅读并同意本政策后使用；请勿在对话中输入与办理事项无关的本人或他人敏感个人信息。监护人如发现未成年人未经同意使用 AI 服务，可联系我们处理。

## 七、跨境处理

默认的 DeepSeek 接口位于中国境内。您也可以自行填写其他 OpenAI 兼容接口；如果该接口位于境外，您的对话、工具结果与 API Key 将直接发送至该境外服务提供方，可能构成个人信息出境。我们无法控制您自行配置的第三方服务，请在选择前确认其所在地、隐私政策与合规状态。联网搜索仅在 DeepSeek 接口下启用。

## 八、政策更新

我们可能因功能变化、模型服务调整或法律要求更新本政策。涉及处理目的、数据种类、接收方或跨境传输等重大变更时，我们会通过应用内公告、弹窗或页面提示等方式告知；依法需要重新取得同意的，将在继续处理前征求同意。

## 十、定义与附则

- **AI 服务**：安大通内的 AHUTong Intelligence 对话、工具调用、联网搜索与写操作确认功能。
- **模型服务提供方**：您自行配置的 OpenAI 兼容接口运营方，默认 DeepSeek。
- **工具**：AI 在您设备上调用、用于查询或修改校园数据的既有能力。
- **工具结果**：工具执行后返回给模型的摘要、列表或结构化卡片数据。
- **外部内容**：来自校园通知、邮件、失物招领、网页搜索等非本机权威数据源的内容。
- **对话历史**：保存在设备本地的多会话消息记录。

本政策未尽事项，适用《安大通隐私政策》与相关法律法规。

**本政策自您安装本版本起生效。**
