# 更新提示条

更新提示条仅在主页、课表、学小通、设置四个实际显示底部导航的页面出现。它在系统手势区上方占 52dp，图标和文字整体居中，页面及原导航同步向上让位。底色、进度和波纹延伸到小白条后面，文字和点击区域留在手势区上方；进入子页面立即恢复完整页面空间，下载继续。

普通更新检查成功后显示主题色提示，点击打开原版本更新弹窗。“稍后更新”保留提示；“跳过此版本”成功写入现有跳过设置后隐藏。手动检查仍能打开弹窗。下载按钮关闭弹窗，进度与完成态显示绿色；填充经过文字时同步切换文字颜色，保证对比度。总大小未知时使用从左向右铺开的实心水波，完成后停在“安装”，由用户点击启动系统安装。

下载失败先回退进度并显示“下载失败”，一秒后重试可恢复的网络错误，连续自动重试最多三次。校验、来源、大小和本地存储等错误保留失败状态，点击提示条可打开原弹窗查看原因并手动重试。下载器的镜像、重定向、SHA-256、大小校验及临时文件处理保持原有规则。

强制更新在首次提示后的三秒前台时间到达时开始下载，退到后台暂停首次倒计时。下载完成不立即弹窗或安装；绿色就绪提示每三秒播放两次相隔 300ms 的水波。下次回到前台，以及冷启动检查发现强更安装包已就绪时，恢复原不可关闭的更新弹窗。后台不播放提示波纹。
