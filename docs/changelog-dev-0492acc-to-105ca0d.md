# 安大通 ChangeLog（0492acc → 105ca0d）

> 基线：master `0492acc`｜规模：67 个功能/修复提交 + 3 次合并（含数据层 19 模块大改）
> 覆盖 v3.4.0 开发周期（2026-09-13 ~ 2026-09-24）

## 一、新功能

### 校园卡账单（全新）
- **交易流水**：总余额 + 本月收支汇总 + 逐笔流水（收入绿/支出红马卡龙图标），滚到底自动分页加载
- **三维筛选**：类型（支出/收入）× 金额区间 × 时间（当月/全部时间），条件可交集
- **账单统计页**：消费分析引擎（移植自 Ahu_Plus）——支出趋势平滑折线、食堂 vs 非食堂拆分、各食堂排行、早午晚餐点分布、非食堂分类、商户 Top、高消费日（点按看当日明细）
- **商户名认知版**：流水直接显示学生叫法（「北二区食堂一楼」→「榴园食堂一楼」），与统计引擎共用同一张映射表

### 全局自定义背景（全新）
- 任意页面挂自定义背景图（相册选图、按屏幕比例裁剪、亮暗遮罩 0-100% 可调）
- 从背景图量化取主色调，一键设为全局主题色
- 开启背景时全场景玻璃卡片自动加深模糊、加厚着色，文字可读性优先

### 隐私政策正式版（全新）
- 内置自研轻量 Markdown 渲染引擎（零第三方依赖，标题/加粗/列表/表格/链接全支持，亮暗主题自适应）
- 首启弹窗直接展示政策全文（可滚动、按钮常驻底部）
- 设置页「隐私政策」常驻入口 + 政策版本机制（政策更新自动重新征得一次同意）

### 学习通日历增强
- **查看题目**：作业详情弹窗新增入口，App 内 WebView 只读打开题目页（登录态自动注入、移动端排版适配、风控命中即熔断提示）
- **同步节流**：已结课课程整门跳过、已完成作业不再重复拉详情页——同步提速且对超星风控友好
- 课程任务页改版：总览独立成卡，全部课程合并一张卡片 + 行间细分隔线

### 主页与导航
- **明日课程预告**：今日课程全部结束后自动切换展示明日课程
- **天气胶囊**：主页天气大卡取消，收敛为标题栏胶囊（图标 + 温度 + 雨情；无雨主题色、有雨暖黄）
- **身份码小工具**：一键拉起淘宝 App 内菜鸟驿站身份码页（tbopen scheme，未装淘宝回退浏览器）
- 外观设置聚合：主题色 / 深色模式 / 主页背景 / 界面风格套装 / 组件槽位混搭集中一处
- 课程卡状态徽标收为纯圆角小胶囊；账单标题栏图标全套换新（iconpark 线性）

## 二、架构创新

- **数据层模块化**：19 个 Gradle 模块拆分（core/data/feature 三层），模块边界有单元测试门禁（ModuleBoundaryTest）；学习资源索引/下载切换至 ahutong-storage 主备双端点
- **UI 组件契约体系（ComponentPack）**：按钮/开关/弹窗/选择器等全部走「契约 + 三主题实现」槽位，主题实验室支持逐组件混搭（Miuix / Material / 曜光），组件替换不改业务代码
- **会话自愈重构**：续期失败分「瞬时抖动/凭据拒绝」两类，瞬时失败冷却窗自动再试——校园网抖动不再逼用户重新登录；登出后彻底封禁自动续期
- **跨天自愈**：App 常开或后台挂过午夜，前台 60 秒对表 + 回前台即重算周次/课程/提醒
- **凭据加固**：Android KeyStore 密钥失效（wipe/换机）兜底处理，法律同意记录改为设备级存储（修复登录前同意、登录后重复弹窗）
- **测试文化**：分析引擎、MD 解析器、会话策略、同步节流判定、资源索引全部带单元测试

## 三、修复工作

- **P1：曜光下全部开关失效**——玻璃开关手势引擎不消费点按，与父行回调双触发互相抵消；改为行统一接管点击（设置页开关行同款隐患一并根治）
- 隐私弹窗长内容按钮被挤出屏幕（弹窗内容区 weight 修复）
- 账单统计页卡片全部叠在一起（槽位误绑）/ 统计每次进入干等（进程内缓存：秒显旧数据 + 后台静默重算）
- 标题栏图标在 Miuix/Material 下消失（painter 图标补齐全部渲染分支）
- 外观页卡片玻璃效果与偏好设置页不一致（backdrop 透传补齐）
- 课程条滑动阴影被裁出矩形硬边 / 弹窗骨架重复五份等 P0 级视觉债务清理
