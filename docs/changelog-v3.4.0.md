# 安大通 v3.4.0 更新日志

> 基线：上游 master `0492acc` → 本版 `e7d27ae`
> 规模：55 个功能/修复提交 + 1 次上游数据层模块化大合并（19 模块）
> 发布时间：2026-09-23

---

## 🌟 亮点功能

### 校园卡账单 —— 全新上线
- **交易流水全链路**：总余额、本月收支汇总、逐笔流水（收入绿 / 支出红马卡龙图标），滚到底自动加载
- **筛选**：类型（支出/收入）× 金额区间 × 时间（当月 / 全部时间），三维可交集
- **账单统计**：消费分析引擎（移植自 Ahu_Plus，特此致谢）——支出趋势平滑折线、食堂 vs 非食堂拆分、各食堂排行、早午晚餐点分布、非食堂分类、商户 Top、高消费日（点按看当日明细）

### 自定义主页背景 —— 全新上线
- 相册选图，按屏幕比例自动裁剪
- 亮暗遮罩滑杆（0-100%，默认 50%）：亮色罩白、暗色罩黑，图片始终清晰
- 「从背景图取主题色」一键联动全局主题色
- 开启背景时全场景玻璃卡片自动增强可读性（模糊加深、着色加厚），关闭即还原

### 隐私政策 —— 正式版全文上线
- 内置轻量 Markdown 阅读器（自研渲染引擎，零第三方依赖）
- 首启弹窗直接展示政策全文（可滚动，操作按钮常驻底部）
- 设置页新增「隐私政策」常驻入口，随时查阅
- 政策版本机制：政策更新后所有用户将重新收到一次全文确认（合规要求）

### 主页天气 —— 胶囊化
- 原大卡片取消，收敛为标题栏胶囊：图标 + 温度 + 雨情
- 无雨显主题色（天气图标），有雨显暖黄（雨伞图标），点按进天气详情页

### 课程体验
- **明日课程预告**：今日课程全部结束后，主页课程卡自动切换为明日课程（状态「明日课程」，大标题仍按今日算「空闲」）
- 课程卡片状态徽标收为纯圆角小胶囊，更精致
- 课程条滑动阴影修复（滑动时阴影不再被裁出矩形硬边）

## 🎨 外观体系

- 设置页「外观」升级为「外观设置」，主题色 / 深色模式 / 主页背景 / 界面风格套装 / 组件槽位混搭全部集中一处
- 外观设置页卡片与偏好设置页视觉完全统一（玻璃质感、边距、分区间距）
- 账单页标题栏三图标换新（iconpark 线性风格），全主题下均正常显示

## ⚙️ 底层（普通用户可跳过）

- 合入上游数据层模块化大改（19 个模块），学习资源索引/下载切换至 ahutong-storage 服务
- 会话续期重构：失败分「瞬时抖动 / 凭据拒绝」两类，瞬时失败冷却窗外自动自愈——**校园网抖一下不再逼你重新登录**；登出后彻底封禁自动续期
- 跨天自愈：App 常开或后台挂过午夜，回来自动按新的一天重算周次/课程/提醒
- 隐私同意记录修正为设备级存储（修复登录前同意、登录后重复弹窗的问题）
- 分析引擎与关键解析器新增单元测试覆盖（统计口径、MD 解析、会话策略）

## ⚠️ 已知事项

- 政策全文弹窗内容较长是合规要求（逐条可读），按钮固定底部不会走失
- 「液态玻璃」独立皮肤已并入「曜光」体系，原液态玻璃用户自动迁移至曜光
